# Distribution audit

Prepared from the existing `averlo-studio/src/lib/showcase/runtime` input-based renderer. Motion, content layout, composition, input preparation, palette/balanced strategy and render-integrity routines are retained. The input renderer is unchanged.

Removed from this distribution: the private Figma-derived NILA page component, Figma file/node identifiers from default manifest, reference video analysis/import/preview scripts, stale evidence and private geometry snapshots, Docker deployment files, personal absolute symlinks, and all source `working` data. The default manifest and background data are replaced with synthetic sample values.

The sample raster is generated by `scripts/create-sample.py` using geometric shapes and OpenCV's built-in text, without external images or font files. No client screenshots are included. Existing motion track names are internal bindings only, not copied client content.

Third-party libraries retain their own package licenses; no dependency license is replaced. Averlo source distribution terms remain to be selected before publishing. This is a private local candidate, not a public release.
